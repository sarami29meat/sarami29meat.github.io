How I Built Twitter AI Filter

May 10, 2026

Twitterのリプライ欄を見てたら、なんか変なのが増えてきた。「素晴らしい投稿ですね！とても参考になりました」みたいなやつ。どう見てもAIが量産してる。気になって仕方なかったので、自分でフィルターを作ることにした。

どうやって判定するか

大きく2つのスコアを組み合わせている。

  • テキストスコア：AI特有のフレーズを日英両方でリスト化してパターンマッチング
  • アカウントスコア：作成日・フォロワー数・投稿数・デフォルトアイコンなどのシグナル

2つを重み付けして合算し、閾値を超えたら折りたたむ。デフォルトは35点。ポップアップからいつでも調整できる。

一番詰まったところ

Chrome拡張はページとは独立した環境で動くので、Twitterがブラウザに送ってくるデータに直接触れない。そこでページと同じ環境で動く別スクリプトを用意して、取得したデータをイベント経由で渡す構成にした。地味に面倒だったけど、これで動くようになった。

I noticed something weird in Twitter's reply section — the kind of comments that scream "素晴らしい投稿ですね！" (Great post!) in that unmistakable AI way. It was clearly being mass-produced. It bothered me enough that I decided to build my own filter.

How detection works

Two scores combined:

  • Text score: pattern matching against a list of AI-typical phrases in both Japanese and English
  • Account score: signals like account age, follower count, post count, default profile icon

Both are weighted and summed. If the total exceeds a threshold (default: 35/100), the reply is folded. You can adjust the threshold anytime from the popup.

The tricky part

Chrome extensions run in an isolated environment, so they can't directly access data Twitter loads in the page. I worked around this by injecting a script that runs in the same environment as the page itself, then passes data across via custom events. A bit fiddly, but it works.
